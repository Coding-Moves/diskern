# Release-readiness review — 2026-09-12

This is a snapshot of `main` at
[the reviewed commit](https://github.com/Coding-Moves/diskern/commit/8abd5cbcc61a41ed50b41cc63fc259bd4b62b777),
after the v0.2.0 release. It records the checks and remaining work identified
in the review; linked issues carry their current status.

## Recommendation

Hold the next release until Windows CI passes and the scan-accounting,
root-error, and updater-coordination problems below are resolved. Run desktop
tests in CI and test the actual installers before publishing.

For example, overlapping roots produced this result from one 4-byte file:

```text
One root:                 1 file, 4 reclaimable bytes, no duplicate set
Parent plus child root:   2 files, 8 reclaimable bytes, 1 duplicate set
```

The duplicate set contains the same pathname twice. A separate hard-link
fixture also reproduced the existing accounting issue
[#66](https://github.com/Coding-Moves/diskern/issues/66).

Existing issue [#109](https://github.com/Coding-Moves/diskern/issues/109) tracks
desktop test execution in CI. The premise of
[#73](https://github.com/Coding-Moves/diskern/issues/73) needs narrowing: the
CLI now has ten integration tests that run the binary, though further output
and error coverage remains useful.

Use [the release checklist](../RELEASING.md) for the current commands and
publication steps. Recheck CI and these issues on the actual release commit;
this snapshot is not approval of a later version.
